# تمرین‌های مقدماتی پایتون (Python Basics)

این پوشه شامل کدها و تمرین‌هایی است که برای تسلط بر مفاهیم پایه‌ای و ساختارهای اصلی زبان برنامه‌نویسی پایتون نوشته شده‌اند.

## 📂 محتویات پوشه
در این بخش، تمرین‌های مربوط به مباحث زیر قرار دارند:
*   **توابع (Functions):** پیاده‌سازی دستی توابع معروف مانند `max`، `min`، `len` و الگوریتم‌های مرتب‌سازی (مانند Bubble Sort).
*   **ساختارهای کنترلی:** استفاده از حلقه‌ها (`for`, `while`) و دستورات شرطی (`if`, `else`).
*   **ساختمان داده‌ها:** کار با لیست‌ها، رشته‌ها و دیکشنری‌ها.
*   **الگوریتم‌های پایه:** مانند تشخیص اعداد اول (Prime Numbers).

## 🎯 هدف
هدف از این تمرین‌ها، درک عمیق منطق برنامه‌نویسی و چگونگی کارکرد توابع و ساختارهای داخلی پایتون، بدون استفاده از توابع آماده است.
