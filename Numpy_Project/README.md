# پروژه‌های محاسباتی با NumPy (NumPy Projects)

این پوشه شامل تمرین‌ها و شبیه‌سازی‌های علمی است که با استفاده از کتابخانه قدرتمند NumPy در پایتون پیاده‌سازی شده‌اند. NumPy به دلیل سرعت بالا در عملیات برداری (Vectorization)، ابزار اصلی برای محاسبات علمی است.

## 📂 لیست پروژه‌ها و مباحث

*   **حل دستگاه معادلات خطی:** استفاده از `np.linalg.solve` برای حل مسائل جبر خطی (مانند محاسبه جریان در مدارهای الکتریکی).
*   **شبیه‌سازی مونت‌کارلو (Monte Carlo):** تخمین عدد پی (\(\pi\)) با استفاده از تولید اعداد تصادفی و مساحت دایره.
*   **شبیه‌سازی واپاشی رادیواکتیو:** مدل‌سازی کاهش تعداد هسته‌های رادیواکتیو در طول زمان با استفاده از توابع نمایی (`np.exp`).
*   **شبیه‌سازی امواج و نوسان:** تولید و تحلیل امواج مثلثاتی (`np.sin`, `np.cos`) و بررسی نوسان‌های میرا.
*   **آمار و احتمال:** شبیه‌سازی پرتاب سکه و تاس و محاسبه میانگین و توزیع داده‌ها.
