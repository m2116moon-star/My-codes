# My-codes
# تمرین‌های پایتون من

سلام! این مخزن شامل کدها و تمرین‌هایی است که در مسیر یادگیری زبان برنامه‌نویسی پایتون نوشته‌ام.

## موضوعاتی که تا الان کار کرده‌ام:
- توابع پایه (تشخیص عدد اول، مرتب‌سازی لیست)
- شبیه‌سازی‌های فیزیکی (محاسبه سقوط آزاد)
- کار با کتابخانه NumPy (عملیات ماتریسی، ماسک‌گذاری، برش آرایه‌ها)

## ساختار مخزن:
- به مرور زمان فایل‌ها و پروژه‌های جدیدی به اینجا اضافه خواهد شد.
